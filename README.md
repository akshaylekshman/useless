# THE BUTTON
### *"An innovative solution to a problem that does not exist."*

**Button Interaction Research Facility · Experiment BTN-001**

---

## What is this?

A completely useless website made purely for fun.  
One button. Infinite nothing. Increasing amounts of your money.

---

## Features

- 🔘 **The Button** — Click it. Nothing happens. Keep clicking.
- 📊 **Infinite loading bar** — Approaches 100% forever. Never gets there.
- 💸 **Payment system** — Pay ₹1 → ₹2 → ₹3... to unlock the same useless thing.
- 🏆 **Achievements** — Completely meaningless milestones.
- 📈 **Stupidity Score** — A score that measures nothing useful.
- 🎲 **Random events** — Button emergencies, fake wins, philosophical crises.
- 🌀 **Loading goes backwards** — Occasionally.
- 🏆 **Demo Leaderboard** — People who could have closed the tab but didn't.
- 💾 **Progress saved** — localStorage. Yes, we remember you came back.
- 🌌 **Secret ending** — Reach Page 100.
- 🔊 **Sound effects** — Generated via Web Audio API. No external files.

---

## How to run

Just open `index.html` in any modern browser.  
No build step. No server required. No point.

```
double-click index.html
```

Or use VS Code Live Server for auto-reload.

## Payment

This is a **demo project**. No real payments are processed.  
The "Pay" button shows a fake QR code and auto-succeeds when you click "I PAID (DEMO)".

The joke: you're paying more and more money to unlock the same stupid button.
